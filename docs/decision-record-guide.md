# Decision records

Use ADRs for explicit project decisions. Research notes hold evidence; open
questions hold unresolved choices. A candidate method is not a decision.

Start with Status, Context, Decision, Consequences, Alternatives considered and
Open questions. Link the supporting notes and record superseding decisions
without erasing earlier reasoning. Do not invent rejected alternatives.


Copy template/decision-record.md for a new decision. This format does not prescribe which technical option to choose.
